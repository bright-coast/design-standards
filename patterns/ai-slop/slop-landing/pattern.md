## Rule
<p><strong>Don&rsquo;t.</strong> Ship the landing-page version of the same habit: an adjective stacked on a vague noun as the headline, a big ambient glow behind the hero, two equal-weight buttons, a trust number nobody can check, and a row of icon-plus-adjective feature cards.</p>
<p><strong>Why it reads as machine-made.</strong> It is the dashboard habit on a different surface, decoration standing in for a real decision, so nothing on the page is attached to the actual product.</p>
<p><strong>Fix.</strong> One line per tell below. The full write-up, the demo and the CSS live in AI Landing Page Tells (Visual, entry 22), which stays where it is.</p>
## Avoid
- <span>A headline that stacks an adjective on a vague noun (&ldquo;Supercharge your workflow with AI&rdquo;). Fix: state the outcome in plain text.</span>
- <span>A big ambient gradient glow behind the hero. Fix: put the colour on the product screenshot itself.</span>
- <span>Two equal-weight calls to action, especially both left-aligned in a row. Fix: one true primary, one visibly quieter secondary.</span>
- <span>&ldquo;Trusted by 10,000+ teams&rdquo; with no attribution. Fix: one named quote with a role and a face.</span>
- <span>Feature cards that are an icon plus an adjective (a lightning bolt beside &ldquo;Fast&rdquo;). Fix: a card that shows the real product screen doing the thing.</span>
